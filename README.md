# My-Python-Learning-Journey

## 项目简介
本仓库用于记录我的 Python 学习过程，存放课堂练习、小案例与作业代码；包含基础计算、小游戏等示例，用来练习 Python 语法、熟悉 Git 与 GitHub 使用。

## 文件说明
- `hello_calc.py`：简易数字求和程序，练习输入输出与变量运算
- `guess_game.py`：猜数字小游戏，练习随机库、条件判断
- `README.md`：项目说明文档

## 代码说明
1. **hello_calc.py**
   - 使用 `input()` 获取用户输入，转为整数；
   - 通过加法运算得到结果并打印输出；
   - 核心：基础交互、类型转换。
2. **guess_game.py**
   - 使用 `random.randint()` 生成随机数字；
   - 通过 if 判断比较猜测值与答案；
   - 核心：随机数、分支控制。

## 学习心得与规划
浏览 GitHub 上优秀 Python 项目后，我发现清晰文档、版本管理非常重要。这次任务让我学会用 Markdown 写说明、用 Git 保存学习痕迹。后续我会持续在这个仓库上传课堂练习、作业和小项目；每次提交附带简短说明，用 README 更新学习进度，记录遇到的问题与解决方案，把仓库作为展示编程能力、复盘学习的线上档案。
